# Video Poker
Et video poker spill utviklet som individuell skoleoppgave.

## Teknologier 
- React
- Typescript
- Zustand
- React Router
- CSS

## Funksjonalitet
- Opprette og velge spiller
- Spille video poker
- Velge innsats
- Beholde og kaste kort
- Beregne pokerhånd og gevinst
- Lagre spilltilstand lokalt
